# PDF fonts

Geist Regular and Bold, the app's UI font, from the `geist` npm package
1.9.2 (`dist/fonts/geist-sans/`), for PDF export: jsPDF's built-in
Helvetica has no Cyrillic. The package's exports serve Next.js only, so
the two files are kept here. Licensed under the SIL Open Font License 1.1
(`OFL.txt`).
