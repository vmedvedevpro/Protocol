# Meetily – Actually Free release history

The notes in this folder are release notes and release records of
[Meetily – Actually Free](https://github.com/TylerBuza/Meetily-ActuallyFree), the
project Protocol forked from at commit `3130d16` (source version 0.2.22). They
are kept for history: Protocol did not publish these releases, and the notes are
not updated as Protocol's code changes.

- Issue and PR numbers (`#42`, `PR #36`) refer to
  [TylerBuza/Meetily-ActuallyFree](https://github.com/TylerBuza/Meetily-ActuallyFree),
  not to Protocol, unless the text names or links
  [Zackriya-Solutions/meetily](https://github.com/Zackriya-Solutions/meetily),
  the original Meetily.
- Versions (0.2.x and the `-macos` previews), workflow runs, and download names
  are that project's.
- Protocol's releases are on
  [GitHub Releases](https://github.com/vmedvedevpro/Protocol/releases) and in
  [CHANGELOG.md](../../CHANGELOG.md), whose
  [Meetily – Actually Free history](../../CHANGELOG.md#meetily--actually-free-history-up-to-the-fork-at-3130d16)
  part is the changelog of these releases.
